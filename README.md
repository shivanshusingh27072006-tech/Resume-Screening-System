# AI Resume Screening & Ranking System

An NLP-based web application built with Python and Streamlit that automatically evaluates and ranks multiple candidate resumes against a given Job Description using TF-IDF and Cosine Similarity.

## 🛠️ Tech Stack
- **Python** (3.13)
- **Streamlit** (Web UI)
- **Scikit-learn** (TF-IDF & Cosine Similarity)
- **pdfplumber** (PDF Text Extraction)
